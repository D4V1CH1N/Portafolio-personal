# Página Personal - David Zalles (Chato)

Proyecto de frontend desarrollado para la materia de la carrera de Ingeniería en Sistemas (UPDS). Consiste en una página web personal responsiva que presenta mis pasatiempos, intereses profesionales, horario diario y gustos personales.

## Tecnologías utilizadas

* HTML5
* CSS3
* Bootstrap 5.3
* Bootstrap Icons

## Estructura de la página

* **Barra de navegación (Navbar):** Menú superior fijo con accesos directos a cada sección de la página y enlaces a perfiles externos[cite: 1].
* **Carrusel de imágenes:** Cabecera principal con tres fotografías representativas de mis áreas de enfoque[cite: 1].
* **Pasatiempos e Intereses:** Tarjetas informativas divididas en actividades recreativas (no productivas) y áreas de desarrollo profesional y académico (productivas)[cite: 1].
* **Horario diario:** Tabla con diseño tipo hoja de cálculo (Sheets) detallando las actividades fijas del día a día[cite: 1].
* **Favoritos (Música y Videojuegos):** Tablas organizadas con contenedores desplazables listando mis artistas musicales y sagas de videojuegos preferidas[cite: 1, 3].
* **Frase característica y Gráfico:** Sección dedicada a mi lema personal acompañada de barras de progreso que representan mi distribución de tiempo diaria[cite: 1].
* **Footer:** Pie de página con enlaces directos a mis tres redes principales (GitHub, Spotify e Instagram)[cite: 1].

## Ejecución

Para visualizar el proyecto localmente, basta con clonar o descargar este repositorio y abrir el archivo `index.html` en cualquier navegador web moderno.
